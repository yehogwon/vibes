- Apps with a `cask.sh` (Jots, Moments) ship through Homebrew by running the Release workflow (`.github/workflows/release.yml`) on main, which bumps the app's last `<app>-v<version>` tag (or takes an exact, higher version), builds the app as that version, tags the release and writes the cask from `<app>/cask.sh` (never edit casks in `yehogwon/homebrew-vibes`), whose quarantine-clearing `postflight` must not become `postflight_steps`. `CFBundleShortVersionString` in `<app>/Resources/Info.plist` stays `0.0.0`; never bump it. Each such app is a choice of that workflow's `app` input.
- main requires one check, "CI", from `.github/workflows/ci.yml`. A new app needs its own job there, listed in the CI job's `needs`.
- UI work follows `DESIGN.md`, and is reviewed with the apple-design skill (`.claude/skills/apple-design`) before it ships.
